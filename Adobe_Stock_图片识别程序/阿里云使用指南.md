# 阿里云通义千问VL - 使用指南

## 获取API密钥

1. 访问 https://dashscope.aliyuncs.com/
2. 注册/登录账号（需实名认证）
3. 开通"通义千问VL"服务
4. 创建API密钥（格式：`sk-xxxxxxxxxxxxx`）

**注意**：密钥只显示一次，请立即保存。

## 配置程序

编辑 `config.json`，填入密钥：
```json
{
  "alibaba_api_key": "sk-你的密钥",
  "input_folder": "C:/Users/ycl/Desktop/图库程序1/待识别图片",
  "output_folder": "C:/Users/ycl/Desktop/图库程序1/识别结果"
}
```

## 运行程序

双击 `运行.bat` 或命令行执行：
```bash
py alibaba_image_recognizer.py
```

## 输出格式

CSV文件包含：
- 文件名：完整文件名
- 标题：英文描述（20-50字符）
- 关键词：英文关键词，逗号分隔
- 类别：数字代码（1-21）
- 发布：空白

## 费用说明

- 新用户有免费额度
- 每张图片约0.01-0.05元
- 100张图片约1-5元

## 常见问题

**API密钥无效**：检查格式是否以 `sk-` 开头

**余额不足**：充值或检查免费额度

**识别速度**：正常2-5秒/张，取决于图片大小
