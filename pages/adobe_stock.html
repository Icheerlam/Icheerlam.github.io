[ ADOBE STOCK // IMAGE RECOGNIZER ]

本地 AI 程序，批量生成 Adobe Stock 关键词和标签

Program Overview // 功能概览

Adobe Stock 图片识别工具是一款本地 AI 程序，批量处理图片文件夹，自动为每张图片生成符合 Adobe Stock 上传标准的标题、关键词和分类目录，支持 CSV 批量导出。

  • AI 图片识别 — 调用阿里云通义千问 VL 模型，分析图片内容
  • 关键词生成 — 自动提取最多 49 个英文关键词（对象、场景、动作、色彩、情绪等）
  • 标题生成 — 生成简洁精准的英文图片描述标题
  • 分类映射 — 匹配 21 个 Adobe Stock 标准分类目录
  • 并发处理 — 支持多线程批量处理，默认 5 并发
  • CSV 导出 — 输出符合 Adobe Stock 上传格式的 CSV 文件

API Configuration // API 配置

程序使用阿里云 DashScope 服务，支持通义千问 VL 模型。首次使用需配置 API Key。

> 请勿将 API Key 上传至公开仓库，config.json 已在 .gitignore 中排除

  • 模型：qwen-vl-max（图片识别）/ qwen-max（提示词生成）
  • 并发：默认 5 线程，可在 Web 界面调整
  • 图片压缩：最大边长 800px，JPEG 质量 75%，加快处理速度
  • 超时：API 请求超时时间 30 秒
