# 作品后台设计

## 目标

新增独立的“作品后台”页面，让站点所有者集中查看 Graphic 作品媒体，并区分“已展示在网页”和“未展示”。

## 数据范围

后台扫描以下目录中的图片与视频：

- `works/graphic`
- `works/3d`
- `assets/portfolio-uploads`

`data/graphic-works.json` 是展示状态的唯一依据：文件被作品清单引用即为“已展示”，否则为“未展示”。

## 页面与交互

- 新增后台页面入口，仅在本地管理流程中使用。
- 顶部展示统计数字，并提供“全部 / 已展示 / 未展示”筛选。
- 每个媒体卡片显示缩略图、文件名、媒体类型、展示状态和区域标签。
- 未展示作品可选择 Graphic、AI 商店或 3D 区域后加入网页。
- 已展示作品可从网页移除；该操作只更新清单，不删除原始文件。
- 实际删除媒体文件须单独确认，初版不提供该操作。

## 保存与异常

- 添加或移除展示后写回作品清单，并保留浏览器本地草稿。
- 无法加载的媒体显示错误状态，不会阻止其他作品管理。
- 不保存临时 `blob:` 地址；新上传媒体需成功写入本地文件夹后才能作为持久作品显示。

## 验证

- 自动测试目录扫描、状态判断、筛选及加入/移出展示的清单更新。
- 后台不扫描站点其他页面的无关资产。
