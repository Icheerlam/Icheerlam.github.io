# 全站中英文切换设计

## 目标

为网站内所有 HTML 页面提供统一的右下角悬浮语言按钮，支持中文与英文即时切换。覆盖首页、作品页面、演示页面、视频分析功能页及自动生成的分析报告页。

## 范围

- 为仓库内全部对外展示的 HTML 页面接入统一语言模块。
- 为导航、标题、正文、按钮、表单提示、辅助说明和页面标题提供人工编写的中英文内容。
- 品牌名、产品名、文件名、代码、专有缩写及无需翻译的视频素材名称保持原文。
- 不接入在线翻译服务，不增加网络请求或第三方翻译依赖。

## 方案

### 共享语言模块

在 `assets` 下维护全站共用的语言切换脚本和样式。模块负责：

1. 创建或初始化右下角悬浮语言按钮。
2. 读取并校验浏览器中保存的语言偏好。
3. 切换带双语标记的元素、内联双语文本和页面标题。
4. 更新根元素的 `lang` 属性、按钮文案及无障碍标签。
5. 在用户切换后保存偏好，使语言状态在页面跳转后保持一致。

每个页面只负责提供静态中英文内容，不重复实现切换逻辑。

### 内容标记

根据内容结构使用两种明确标记：

- 成对内容节点：分别标注中文和英文，适用于段落、复杂富文本及报告表格。
- 双语属性：同一元素保存中英文短文本，适用于标题、导航项和按钮。

切换只改变显示状态或文本内容，不重建页面主体，以避免影响页面已有动画、事件和媒体状态。

## 交互与视觉

- 按钮固定在视口右下角，所有页面保持一致的尺寸、层级和视觉风格。
- 当前为中文时按钮显示 `EN`，表示点击后切换到英文；当前为英文时显示 `中`。
- 首次访问默认显示中文；此后使用最近一次选择。
- 按钮支持鼠标、触摸和键盘操作，并提供与当前操作一致的 `aria-label`。
- 移动端使用安全边距，避免溢出屏幕或遮挡底部主要操作控件。

## 页面接入

逐一检查仓库中的 HTML 页面：

- 接入共享样式和脚本，路径按根目录页面与 `pages` 子目录页面分别处理。
- 移除或兼容现有页面内重复的语言切换实现，确保只有一个按钮和一个状态来源。
- 补齐所有用户可见中文内容的自然英文译文。
- 对分析报告保留原有表格结构，仅增加对应英文内容。

## 状态与异常处理

- 使用固定存储键保存 `zh` 或 `en`。
- 存储不可用、值无效或脚本执行异常时回退为中文，页面中文内容仍可正常阅读。
- 页面若暂时缺少某项英文内容，则保留中文原文，避免出现空白区域。
- 共享模块重复加载时不重复创建按钮或绑定事件。

## 验证标准

- 仓库内每个对外展示 HTML 页面均出现右下角语言按钮。
- 每页点击按钮后，页面标题和主要可见文字能在中文与英文之间切换。
- 从任一页面选择英文后，进入其他页面仍显示英文；切回中文同理。
- 刷新页面后保留最近选择。
- 页面中不存在重复语言按钮，已有导航、动画、音频、视频和交互不受影响。
- 桌面端与移动端按钮均位于可见区域，不遮挡关键操作。

## 测试策略

- 静态检查：枚举全部 HTML 文件，确认共享模块已接入且双语标记完整。
- 单元测试：验证默认语言、偏好读取、切换、持久化、无效存储回退及重复初始化。
- 页面级检查：抽查根目录页面、普通内容页、演示页和分析报告页的实际切换结果。
- 回归检查：确认原有链接、媒体、动画及按钮事件仍可使用。

## 非目标

- 不提供第三种语言。
- 不调用机器翻译接口。
- 不改变页面原有信息架构、视觉主题或作品内容。
- 不翻译用户上传素材内部的图片、音频或视频画面文字。
